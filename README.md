# 🎓 AI Study Planner

> A modern, responsive study planning web application designed to help students organize their learning goals, create personalized study schedules, track progress, and receive AI-powered study recommendations.

## 🌟 Overview

**AI Study Planner** is a web-based study management application that helps students turn their academic goals into structured study plans.

Users can enter their study goal, subjects, available daily study hours, academic level, and study duration. The application then generates a personalized study schedule and allows users to track their progress.

The project is currently built as a frontend application using **HTML, Bootstrap, CSS, and JavaScript**, with AI API integration planned for the next development stage.

---

## ✨ Features

### 📚 Personalized Study Planning

* Enter a specific study goal
* Add multiple subjects
* Select academic level
* Set available daily study hours
* Choose study plan duration
* Generate a personalized study plan

### 📅 Weekly Schedule

* Automatically organize subjects into a study schedule
* Display study sessions clearly
* Track individual study tasks
* Mark completed tasks

### 📊 Progress Tracking

* Track completed study tasks
* Calculate overall progress
* Display progress using a visual progress bar
* Reset progress when needed

### 🤖 AI Study Recommendations

The application includes an AI recommendation section designed to provide personalized learning suggestions based on the student's goals and study plan.

> Currently, the application uses simulated recommendations. Real AI API integration will be added in a future version.

### 🎨 Modern User Interface

* Responsive design
* Dark mode
* Light mode
* Modern dashboard
* Interactive cards
* Smooth animations
* Mobile-friendly layout
* Bootstrap-based responsive grid

### 💾 Local Storage

The application uses browser `localStorage` to save:

* Study goals
* Subjects
* Study preferences
* Progress
* Theme preference

This allows users to continue using their study plan after refreshing the page.
